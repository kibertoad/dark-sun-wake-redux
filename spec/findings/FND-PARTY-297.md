## Observation

Q-PARTY-134 retains the mask-10 reflected-cast route's incoming number
after FND-PARTY-288. This review checks a second necessary condition
of that route, rather than seeking a universal bound on its input.
Offsets are hexadecimal; resource number 1001 is decimal.

### The actual payload test

Overlay 197 +1827 calls 2C5F:0003 with current DI. It copies the
returned offset and segment into BX and ES, then at +1831 tests
word ES:[BX+11] against mask 0080. A clear result selects zero AL
and branches at +1841 to +1859. Only a set result can continue to
the caster test and the +184C call of overlay 208 +0885, whose
accepted result can jump at +1857 to the forwarded-number queue
path +18CA. There is no intervening child call between the returned
pointer and the word test. The instruction test is sixteen-bit; mask
0080 selects bit seven of the byte at payload offset 11, not a bit
of the following byte.

FND-PARTY-068 reads the installed RESOURCE.GFF directory and the
576-byte DATA 1001 payload at file 186CB..1890B. Its first origin
block, all 72 bytes, is zero. Offset 11 lies inside that block, so
the tested bit is clear when the returned pointer supplies that intact
payload. The source identity is length 5724669, XXH3-128
92fe031616f36062f99484b0f728210e (FND-ITEM-057 and the build manifest).
This applies existing direct payload evidence, not an inference from
the table's fantasy class meanings or its total size alone.

Therefore an intact DATA 1001 payload cannot reach +184C or the
+1857 forwarded-number jump through this mask-10 test. It falls
into the separately gated mask-20 path. FND-PARTY-288's signed
0..234 number gate and later preservation conditions still apply
there. This is not an unconditional return from the whole helper.

### The getter binding remains essential

FND-ITEM-057 shows that an equal cache key returns DS:4277 without
checking its contents. A failed miss returns a null pointer without
updating the old key; an accepted miss uses the local output pointer.
None of these outcomes alone proves an intact selected resource at
the flag test. In particular, this code does not check for a null
getter result before dereferencing it. The null/failure case is not
covered by the payload-zero exclusion. No actual failed dereference,
runtime failure or resulting flag value was observed here.

## Interpretation

The mask-10 route does not require proving every incoming number is
below 1001 to exclude the intact-payload case. Its own flag test rules
that case out. Its remaining relevant obligation is the getter's
selected-source/content binding and failure outcome at +1831, together
with any later pointer or buffer alteration and the separate mask-20
continuation. An unbounded formal number alone is no longer a reason
to call this mask-10 route an unconditionally possible 1001 producer.

The getter call at +1827 is itself a possible computed DATA access;
this finding does not remove it from Q-PARTY-124's eighty other sites.
It also does not settle the downstream three clients or all reflected
cast producers. FMT-PARTY-007 stays supported, with no complete
reading, answered queue deletion or changed count of unresolved sites.

## Alternatives

- An admitted intact payload makes this flag clear. A stale, partial,
  modified or differently bound buffer requires its own flag evidence.
- Falling into the mask-20 path does not bypass that path's number gate;
  preserving or changing its DI value remains the existing obligation.
