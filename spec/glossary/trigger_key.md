# trigger_key

The comparison key a one-key or key-pair trigger is looked up by: an `INT16`
the game keeps at `4C0D:0009` in BLD-GOG-EN-1.1 [FND-SCRIPT-028].
object_trigger_key derives it from a negative literal or a kind-specific
field-zero getter result [FND-SCRIPT-034, FND-ACTOR-016]. Actual input and
shared-state admission remain Q-SCRIPT-022. No other build has been described.
