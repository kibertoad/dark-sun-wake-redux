# fn_2D40_3E64

A far routine at `2D40:3E64` in BLD-GOG-EN-1.1 that takes a party slot or the combatant in `turn_combatant` and returns a byte and two indexes; the status panel and the Space key use the first index to pick a record of `combatants` [FND-COMBAT-022, FND-AI-004]. This spec models it as returning that index, or -1 when the byte is 0. Not read. No other build has been described.
