# fn_2D40_3E64

A far routine at `2D40:3E64` in BLD-GOG-EN-1.1 that takes an object number and two pointers. It returns 0 when the number is 9999 or more, the object is not of kind 2, its record number is 42 or more, or that record's `details_index` is 17 or more; otherwise it returns 1. It stores the object's record number of `combatants` and that record's `details_index` through the pointers [FND-COMBAT-072]. This spec models it as returning the `combatants` record number, or -1 when it returns 0. No other build has been described.
