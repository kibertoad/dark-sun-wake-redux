# object_field_types

The type byte of each field number of the generic field accessor, which instruction `0x33` reads to decide whether an expression follows its operator [FND-SCRIPT-024]. A list of 98 `UINT8` the game keeps at `57E0:60ED` in BLD-GOG-EN-1.1, into which the initializer requests `FNFO/2` of `OBJEX.GFF` [FND-CONFIG-150, FND-CONFIG-153]; whether that request fills it before a script runs is (unknown). No other build has been described.
