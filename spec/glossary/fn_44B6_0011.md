# fn_44B6_0011

The far routine at `44B6:0011` in BLD-GOG-EN-1.1, which returns the BIOS shift-key flags through `INT 16h` service 2: bit 0 for the right Shift key and bit 1 for the left [FND-INPUT-005]. The cinematic routines read bits 0 and 1 [FND-VIDEO-002, FND-VIDEO-006]. No other build has been described.
