# fn_2D40_1197

The fight check that the movement routine runs from `2D40:1197` in BLD-GOG-EN-1.1 during a fight: for each other slot it may start an attack through the attack routine. It returns 0 when the movement routine goes on, 1 when it ends the call, and 2 when it ends the call after setting the fight state to 4 [FND-PARTY-199, FND-EXPLORE-014]. Read in part.
