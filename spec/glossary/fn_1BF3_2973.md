# fn_1BF3_2973

The far routine at `1BF3:2973` in BLD-GOG-EN-1.1, which sets a BIOS video mode, 3 for text and `0x13` for 320x200 with 256 colours, and for a mode above `0xFF` sets the low byte's mode and then unchains the VGA into four planes [FND-VIDEO-009]. Read. No other build has been described.
