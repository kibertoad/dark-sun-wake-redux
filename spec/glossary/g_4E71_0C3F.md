# g_4E71_0C3F

A `UINT8` disc-enable byte at `4E71:0C3F` in BLD-GOG-EN-1.1. The known initialization callback sets it after presence succeeds and clears it on metadata failure; presence failure can retain an earlier value. Disc request/play helpers reject zero. A nonzero byte alone proves no device or audible result [FND-SOUND-067, FND-SOUND-094, FND-SOUND-095]. No other build has been described.
