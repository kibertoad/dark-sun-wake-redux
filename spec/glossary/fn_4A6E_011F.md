# fn_4A6E_011F

The far routine at `4A6E:011F` in BLD-GOG-EN-1.1. Its local fallback returns word 255; otherwise it forwards the driver's level-query word [FND-CONFIG-236]. In the ten inspected Copy drivers that query reads the selected sequence's current level, distinct from its target. Preferences retains only the low byte; actual driver/sequence binding and storage admission remain unresolved [FND-CONFIG-237]. No other build has been described.
