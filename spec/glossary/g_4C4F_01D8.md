# g_4C4F_01D8

A table of `UINT16` words the game keeps at `4C4F:01D8`, one per combatant, in BLD-GOG-EN-1.1; the turn routine runs `confusion_roll` when bit 0x100 of the combatant's word is set, and `confusion_roll` clears it [FND-RNG-089]. What the other bits stand for and which code sets bit 0x100 is (unknown). No other build has been described.
