# g_57E0_1A34

A `UINT16` the game keeps at `57E0:1A34` in BLD-GOG-EN-1.1: while it is not `0xFFFF`, a right-button press in the Look mode steps `pointer_mode` to 3 instead of 1 [FND-INPUT-013]. Overlays 175, 187 and 188 store `0xFFFF`, 0 and a loop index in it [FND-INPUT-013]. No other build has been described.
