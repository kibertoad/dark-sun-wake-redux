# fn_187_2802

The routine at code offset `0x2802` of overlay 187 (`DSUN.EXE+0x00072632`) in BLD-GOG-EN-1.1, which returns 1 when a file's length is below the product of the first two words `44DE:04A1` fills in for drive 0, and otherwise shows that the file could not be copied and returns 0 [FND-VIDEO-004]. Read except `44DE:04A1`. No other build has been described.
