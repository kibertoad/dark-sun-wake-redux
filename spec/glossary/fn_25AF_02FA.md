# fn_25AF_02FA

The far routine at `25AF:02FA` in BLD-GOG-EN-1.1, which takes a slot and a cell's bits 0 to 2 and returns 0 when that cell is closed to the slot; for the slots 0 to 3 it reads bit 5 of byte `0x18` of the slot's combatant record [FND-EXPLORE-001]. Read only at its start. No other build has been described.
