# fn_172C_0698

The near room-search helper at `172C:0698` in BLD-GOG-EN-1.1
(FND-SCRIPT-022). It takes a word size and returns a word candidate
offset. An unsigned size-not-below-capacity check calls `fn_5702_00B1`
and, if it returns, returns zero. Other paths scan slot bounds, restart
after collisions and can call `fn_172C_07BB` before retrying. Room checks
use signed double-word comparisons; collision end-plus-one uses wrapped
word arithmetic. It does not allocate or move script-buffer bytes, and
zero is also a valid offset. Complete input provenance and error effects
remain open in Q-SCRIPT-003. No other build has been described.
