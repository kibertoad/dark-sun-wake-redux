# class_combinations

The class combination table: the `DATA` resource 1001 of `RESOURCE.GFF`, an FMT-PARTY-007 the
game requests afresh each time it reads it, in BLD-GOG-EN-1.1 [FND-PARTY-058]. Rules index it as
`class_combinations[origin][first][k]`, `first` the first class's `character_class` code and `k`
0 or the second class's code plus 1, and read each byte as FMT-PARTY-007's `masks` gives it
[FND-PARTY-068].
