# psionic_powers

A table the game keeps at `51F1:07E0` in BLD-GOG-EN-1.1, three bytes for each psionic power 0 to 33 at `51F1:07E0 + 3 * power`. Byte 0 holds `score_code`, the score number in bits 0 to 2 that the power check reads, and `adjust`, the signed byte shifted right by three that it adds; byte 1 is `cost`, the points a use takes; byte 2, `byte_2`, is the upkeep each round a power in effect is kept, 99 for a power that cannot be kept, which also keeps a use from marking it in effect [FND-RNG-046, FND-PARTY-210, FND-MAGIC-007, FND-MAGIC-008]. The values are in the load image and nothing writes them; FND-MAGIC-007 lists all 34 rows. No other build has been described.
