# fn_27E5_00C1

The far routine at `27E5:00C1` in BLD-GOG-EN-1.1, which takes an object slot and a class code and returns the level byte of the first position holding that code, or 0; for an origin byte of 1 it returns 0 when the position is not 0 and position 0's level is not above that level, and 0 when `2D40:3E64` does not find the slot [FND-PARTY-081]. No other build has been described.
