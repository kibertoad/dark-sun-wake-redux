# cell_map

The cell flags of the current region: an FMT-REGION-003 the game keeps in the buffer the far pointer at `57E0:0538` names in BLD-GOG-EN-1.1, filled from the region's `GMAP` resource; the pointer is null when no map is loaded [FND-REGION-005, FND-EXPLORE-001]. No other build has been described.
