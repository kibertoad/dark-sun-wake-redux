# fn_573B_002A

The far routine that gives the list of effect numbers the status panel sorts, at the stub `573B:002A` of overlay 193 in BLD-GOG-EN-1.1. The panel's routine calls it with the combatant, 0 and a buffer that `573B:0025` filled first, and takes up to 35 bytes [FND-COMBAT-022]. Not read. No other build has been described.
