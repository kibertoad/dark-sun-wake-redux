# fn_2D40_2196

The far routine at `2D40:2196` in BLD-GOG-EN-1.1, which fills a caller's array with the entries of an object slot's held objects, ten bytes each, word `+2` the entry's kind and word `+4` its item, and returns their count [FND-CONFIG-143, FND-RNG-035]. Rules write an entry's words as `kind` and `item`. No other build has been described.
