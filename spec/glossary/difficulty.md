# difficulty

The difficulty setting of combat, which the game shows as Easy, Balanced, Hard or Hideous. Rules
write it as 0 to 3 in that order, the order of the labels in the executable's list at `5000:A4B9`
in BLD-GOG-EN-1.1 (FMT-TEXT-004). A value the game keeps, of a type and at a place that are
(unknown).
