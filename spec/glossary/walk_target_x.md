# walk_target_x

A `INT16[]` the game keeps at `4F49:08A3` in BLD-GOG-EN-1.1: for each slot, one word every 19 bytes, the column of the cell a direction key or a Walk click sent the character to, or for some values of `walk_mode` an object slot [FND-EXPLORE-004, FND-RNG-068, FND-EXPLORE-014]. No other build has been described.
