# fn_2C5F_018C

A far routine at `2C5F:018C` in BLD-GOG-EN-1.1 that forwards an object
slot's anchor position and a low-byte mode to `2C5F:01F3`. Its child
subtracts 160/100 from those coordinates, masks off three low bits,
then applies ordered signed boundary tests to the view words before
optional display calls [FND-COMBAT-049]. The end-of-move menu supplies
mode one, then rereads its current slot, figure coordinates and view
words [FND-COMBAT-048]. Admitted bounds, storage, child preservation
and final presentation remain Q-COMBAT-014. No other build is described.
