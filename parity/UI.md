# UI

| Spec ID | Title | Spec status | Code | Tests | Deviations | Status | Notes |
|---|---|---|---|---|---|---|---|
| `FMT-UI-001` | Window resource (WIND) | supported | partial | None | None | supported | `UiWindowResource` reads `number`, `width`, `height` and the children, but takes the child count from the resource length where the format has `child_count`, and reads an image number from offset 58, inside the copied control bytes, where the format has `image` at `0xC2`; both carry `PLACEHOLDER: FMT-UI-001`. The pack `DSUI` keeps the windows. |
| `FMT-UI-002` | Child record of a window | supported | partial | None | None | supported | `UiChildReference` reads `tag`, `number`, `x` and `y`. The runtime `control` pointer and `flags` have no counterpart. |
| `FMT-UI-003` | Button resource (BUTN) | supported | partial | None | None | supported | `UiButtonResource` reads `width`, `height`, `event_mask`, `number_copy`, which it requires to equal `number`, and `icon`, and allows a tail. It does not read `tail_length` or the tail. |
| `FMT-UI-004` | Application frame resource (APFM) | supported | complete | None | None | implemented | `UiApplicationFrameResource` requires 116 bytes and reads `width`, `height` and `event_mask`. |
| `FMT-UI-005` | Edit box resource (EBOX) | supported | partial | None | None | supported | `UiEditBoxResource` requires 168 bytes and reads `number_copy`, `width`, `height` and `event_mask`, but not `image`. |
| `RULE-UI-001` | Which controls the window code offers an event or the pointer to, by their event masks | supported | partial | None | None | supported | `UiEventMasks.Matches` implements `event_matches` without the sign test and is the only mask test; nothing implements `button_can_be_hit` or `edit_box_can_be_hit`, and the screen inputs hit-test every mapped button. It carries `PLACEHOLDER: RULE-UI-001`. |
