# TEXT

| Spec ID | Title | Spec status | Code | Tests | Deviations | Status | Notes |
|---|---|---|---|---|---|---|---|
| `FMT-TEXT-001` | Bitmap font resource | supported | complete | None | None | implemented | `IndexedBitmapFont` requires `glyph_count` to be 256, reads `height`, `char_map` and `glyph_offsets`, and requires each record to end where the next begins. It does not read `unk_04`. `DSFT` keeps the map, height and glyphs. Its tests use synthetic files. |
| `FMT-TEXT-002` | Bitmap font glyph | supported | complete | None | None | implemented | `IndexedBitmapFont` reads `width` and `width * height` pixel bytes. `IndexedGlyphRunRasterizer` and `IndexedGlyphBlockRasterizer` draw the pixels row by row with spacing the caller picks, which the spec does not describe. |
| `FMT-TEXT-003` | Text resource of CR LF lines | supported | complete | None | None | implemented | `GffTextResource` accepts printable ASCII lines ended by CR LF and rejects any other byte, a bare CR or LF, and a missing final CR LF. It accepts empty lines, which no shipped resource has. `DSTX` keeps the lines by resource number. Its tests use synthetic files. |
| `FMT-TEXT-004` | Preferences text block in DSUN.EXE | supported | partial | None | None | supported | `ExecutablePreferencesTextReader` reads the four difficulty labels from file offset `0x4F6F5`, the ten descriptions and the nine About lines, and checks that the descriptions end where the About lines begin. It reads the descriptions from `0x4F72B`, one byte past the start of `description_0` at `0x4F72A`, so the first description loses its first character. It does not read the pointer tables or `unk_010`. It strips the `%C%C%C` prefix of each About line as centering controls, which the spec leaves open, so it carries `PLACEHOLDER: FMT-TEXT-004`. The lines go to `text/preferences.dstx`. Its tests use synthetic files. |
