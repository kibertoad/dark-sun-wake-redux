# SCRIPT

| Spec ID | Title | Spec status | Code | Tests | Deviations | Status | Notes |
|---|---|---|---|---|---|---|---|
| `FMT-SCRIPT-001` | Script resource (GPL and MAS) | supported | partial | None | None | supported | The start-up extractor copies `GPL/135` and `MAS/99` byte for byte into `DSGP` envelopes (`PackedGplScript`) with their tag and number, and keeps the other script resources as opaque `DSOP` payloads. Nothing appends the `0x31` stop byte or reads instructions outside the fixed places the `FirstTyrDialogue*Projection` readers check. |
| `FMT-SCRIPT-002` | String in script code | supported | partial | None | None | supported | `GplPackedString` decodes `STRING_PACKED` as the spec does and treats `STRING_CHARACTER_NAME` as the active character's name. It keeps characters below `0x20` or above `0x7E` instead of reading them as spaces, allows 1,024 characters where the original stops at 299, and rejects kind 2 and any other kind byte where the original reads nothing more. Its tests use synthetic bytes. |
| `FMT-SCRIPT-003` | Script entry point index (GPLI) | supported | missing | None | None | supported | The start-up extractor keeps `GPLI/1` as an opaque `DSOP` payload; nothing reads it. |
| `FMT-SCRIPT-004` | Script trigger record | supported | missing | None | None | supported | The rebuild keeps no script triggers. |
| `FMT-SCRIPT-005` | Record with two script entry points in the 19-byte list | supported | missing | None | None | supported | Nothing models these records. |
| `RULE-SCRIPT-002` | Running a script, reading its code and calling other scripts | supported | missing | None | None | supported | The rebuild has no script interpreter. The `FirstTyrDialogue*Projection` readers check the opcode at fixed offsets of `GPL/135` and turn what they find into dialogue data; `FirstTyrDialogueFlow` in Core applies the effects of each known target by target offset. |
| `RULE-SCRIPT-003` | The script instructions for jumps, calls, returns, if, while, compare, the accumulator and assignment | supported | missing | None | None | supported | No instruction is executed. The response and completion projections check the bytes of assignments, local returns, `if` tests and `while` heads at known offsets of `GPL/135`, and Core applies the flag and number changes they stand for. |
| `RULE-SCRIPT-004` | Reading instruction parameters, expressions, variables and strings | supported | partial | None | None | supported | `FirstTyrDialogueProjection.ReadExpression` walks expressions: literals below `0x80`, variable references of kinds up to `0x0E` with the extended flag, `0x8F`, `0x91` and `0x92`, parentheses and operators. It keeps only the first atom and never computes a value, and it rejects `0x80`, `0x8B`, `0x8C`, `0x90` and `0xB1`. `DialogueCondition` in Core evaluates three condition shapes (a constant, a local flag, a local number equal to a byte) against a state the preview supplies. |
| `RULE-SCRIPT-005` | Script variables start at 0 | sourced | partial | None | None | sourced | The dialogue preview's opening state has local number 0 at 0, local flags 9 and 16 clear and global flag 357 clear, and sets global number 22 to 1, which this rule does not give. It holds only the variables the projections read. |
| `RULE-SCRIPT-006` | The script instruction that draws a random number | supported | missing | None | None | supported | No script instruction draws; `NativeRandom` has no script caller. |
| `RULE-SCRIPT-007` | The script instructions that print text and numbers, show a portrait and play sound and music | supported | partial | None | None | supported | The dialogue preview shows the portrait and prints the text of the `0x54` and `0x4F` instructions the projections find in `GPL/135`, with explicit new lines. It ignores the byte parameter, and nothing prints numbers or plays sound or music from a script. |
| `RULE-SCRIPT-008` | The script instructions that register attack and move-tile triggers | supported | missing | None | None | supported | The rebuild keeps no script triggers. |
| `RULE-SCRIPT-009` | The script trace instructions | supported | missing | None | None | supported | No instruction is executed, and `FirstTyrDialogueProjection.ReadMenu` does not accept trace instructions between menu entries. |
| `RULE-SCRIPT-010` | Script-cache lookup and resource transfer | supported | missing | None | None | supported | The rebuild reads the two packed scripts from its asset pack when the dialogue preview opens and has no script cache. |
