# Research procedure and template review

Tooling maintenance. Outcome: a researcher preserves corrected evidence history,
records a repeatable bounded query, checks the current complete-reading cases,
and starts a rule with Parameters the pinned checker can count. Work from the
unchanged pinned Standard's Identifiers, Complete readings and Findings sections
and template issue 80; make no original-game claim or status change.

Align research-item, AGENTS.md and EVIDENCE-REVIEW.md with whole-entry
supersession, new recorded replacements and citation-dependent status review;
self-contained query values and independent negative-search controls;
register-return loop progress, argument byte writers and deferred ESP cleanup;
allocation/cleanup ordering, combined caller results and adjacent dispatch tables.
Keep PE import-slot and pointer-table evidence tied to the build's bytes. Show
a countable single-name Parameters item in SPEC-ENTRY-TEMPLATES.md, with None.
for a known empty list and unknown/prose cases explicitly uncountable.

Acceptance: review every instruction against its pinned section. Use the
installed checker with synthetic rule objects to confirm one/zero parameters,
valid calls, rejected wrong argument counts and explicit skips for unresolved
Parameters. Do not rewrite existing game rules to silence checker skips.
Existing implement-rows test-section and deviation guidance is audited, changed
only if missing. Exit: pinned digests and links, documentation validation,
synthetic checker controls and full assetless Test.ps1 pass; commit the tooling
batch locally and add relevant details to existing template issue 80.
